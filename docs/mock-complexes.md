# Заглушка ЖК в подборе дома

**Это заглушка MVP с частично выдуманными данными.** В настоящий продукт
её данные попадать не должны.

## Что это

В подборе дома в Ростове-на-Дону вместо настоящих многоквартирных домов
показываются 29 ЖК: касание точки открывает шторку на треть экрана, потянуть вверх —
на весь экран с полной карточкой по макету владельца. Поиск — по районам и ЖК.
Открытого источника ЖК с таким наполнением нет: ЕИСЖС отдаёт отдельные
объекты только по договору, каталог «наш.дом.рф» закрыт защитой от ботов.
А раздел нужно показать.

## Что настоящее, а что нет

| Поле | Откуда |
|---|---|
| название, адрес, район, застройщик | открытый каталог новостроек Ростова (`src: web`) |
| координаты | OSM: дом из набора региона или геокодер Nominatim (`src: osm`) |
| микрорайон | OSM, обратное геокодирование (`src: osm`); где не определился — пусто |
| цена «от», продуктовый, описание, метки инфраструктуры | **придуманы** (`src: mock`) |
| примерная оплата ЖКУ (`utilities`, ₽/мес, миграция 0033) | **придумана** (`src: mock`): 3 500 ₽ + 400 ₽ за каждый миллион цены, в пределах 4 000–8 500 ₽ |
| отзывы и имена в них | **придуманы** (`src: mock`) |
| фото (13 из 29 ЖК) | рендеры с сайтов застройщиков, подпись «© застройщик», поле `photo` (решение владельца 29.09.2026); у остальных — заглушка в цветах MAX |
| рейтинг | среднее звёзд придуманных отзывов |
| `aliases` | внутренние русские написания латинских названий («Грин Сайд» у «GreenSide») — только для поиска, на экран и в API не выходят |
| «Предложить» УК, «+ Оставить отзыв» | ничего не отправляют и не пишут |

Цены и отзывы с ЦИАН, Авито, Домклик, Яндекс Недвижимости и из карточек
каталогов не брались.

В интерфейсе каждая шторка и карточка ЖК помечены «Примерные данные»
(`pickMock` в `public/app/wip.js`).

## Районы на карте (28.09.2026)

Границы восьми районов Ростова — **настоящие**, из OpenStreetMap (ODbL,
подпись на карте уже есть): `lib/pick/mock/rostov-districts.json`, собраны
через Nominatim и упрощены до ~850 точек (18 КБ). Все 29 ЖК лежат внутри
района, указанного у них в `district`, — проверено при сборке.

- Масштаб ≤ 12 — вместо ЖК районы: цветная граница и плашка «Советский ·
  4 ЖК». Нажатие входит в район.
- Ближе — плашки уходят, районы остаются такими же (граница с заливкой), видны ЖК; слипаются в кружок только ЖК одного
  района.
- Вход в район (нажатием или из поиска) — карта охватывает район или, если
  он не влезает в экран, встаёт на масштаб 12 над его ЖК; граница один раз
  вспыхивает, район остаётся на карте, остальные скрыты. Отдалил дальше — снова все районы.
- Поиск района — по названию, народному имени («ЖД», «ЗЖМ», «Сельмаш»,
  «центр»), микрорайонам ЖК, с одной опечаткой от четырёх букв; «районы» —
  все восемь (`matchDistricts`, `lib/pick/mock/districts.ts`). Находится
  и район без ЖК.
- Маршрут `GET /api/pick/districts`; без заглушки ЖК — пустой список.

## Где лежит

- Файл — релиз `mock-complexes-61` в `TaCeiN/domovoy-datasets`, локально
  `var/mock/mock-complexes-61.json`. В репозиторий кода не коммитится.
  Фото — файлы `<slug>.webp` в том же релизе, локально `var/mock/photos/`.
- База — таблица `mock_complex` (миграции 0023–0024) и фото в
  `mock_complex_photo` (миграция 0032, bytea: том вложений не нужен,
  `mock:clear` чистит всё). Раздаёт `GET /api/pick/mock-photo/:slug` без входа.
- Вид по референсу владельца (29.09): метка — иконка высотки
  (`public/app/screens/pick-icons.js`), чипы «ЖК / Районы», на трети шторки —
  плашка с фото, раскрытая — фото, вкладки «О ЖК / Отзывы / Застройщик /
  Инфраструктура».
- Код — `lib/pick/mock/`, `db/mock-load.ts`, `public/app/screens/pick-mock.js`,
  развилки в `server/routes/pick.ts` и `public/app/screens/pick.js`.
- ♥ у ЖК хранится только на устройстве (`localStorage`, ключ `domovoy-pick-fav`).

## Команды

    npm run mock:load                                  из релиза
    npm run mock:load -- --file var/mock/mock-complexes-61.json
    npm run mock:clear                                 выключить
    npm run prod:mock                                  на бою
    npm run prod:mock -- --clear                       выключить на бою

Режим включается данными: пока в `mock_complex` есть строки, карта,
поиск и карточка подбора показывают ЖК. Пусто — настоящие дома, ответы
маршрутов прежние (закреплено тестом в `server/routes/pick.test.ts`).
Битый файл не загружается вовсе: проверка перечисляет ошибки и ничего
не пишет.

## Как убрать

1. Выключить: `npm run prod:mock -- --clear`.
2. Выпилить: удалить `lib/pick/mock/`, `db/mock-load.ts`,
   `public/app/screens/pick-mock.js`, `public/app/screens/pick-icons.js`
   и их строки в `scripts/check-front.mjs`, маршрут `/api/pick/mock-photo`,
   развилки `mock` в `server/routes/pick.ts`, `server/routes/pick.test.ts`
   и `public/app/screens/pick.js`, стили `.mock-*` в `public/styles.css`,
   `WIP.pickMock`, команды `mock:*` и `prod:mock`, `mock_complex` в
   `lib/test-db.ts` и `db/schema.ts`; миграцией удалить таблицы
   `mock_complex_photo` и `mock_complex`; снять релиз `mock-complexes-61`; удалить этот файл.
